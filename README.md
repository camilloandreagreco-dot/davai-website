# Davai website

The marketing site for Dav.ai by TrustPavilion, served by GitHub Pages at https://davai.si.

- `index.html` is the whole site (styles and scripts inline).
- `og.png` is the link preview image; `favicon.svg`, `favicon-32.png` and `apple-touch-icon.png` are the icons.
- `CNAME` tells GitHub Pages to serve the site on davai.si.
